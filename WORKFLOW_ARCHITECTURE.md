## 快速参考 / Quick Reference

### 创建 1.21.11 发布的三种方法

#### 方法 1: GitHub UI (推荐)
```
1. Actions → Create Release
2. Run workflow
3. Tag: 1.21.11
4. Release name: EssentialsX 1.21.11 for Paper 1.21.11
5. Run!
```

#### 方法 2: Git 命令
```bash
git tag 1.21.11
git push origin 1.21.11
```

#### 方法 3: GitHub CLI
```bash
gh workflow run create-release.yml \
  -f tag=1.21.11 \
  -f release_name="EssentialsX 1.21.11 for Paper 1.21.11"
```
