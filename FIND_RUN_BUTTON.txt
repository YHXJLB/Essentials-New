🎯 快速总结 / Quick Summary

找不到按钮的原因：
Reason for no button:
  ❌ 工作流在特性分支上
  ❌ Workflow is on feature branch
  ❌ GitHub 默认显示主分支
  ❌ GitHub shows main branch by default

解决方法：
Solution:
  ✅ 在 Actions 页面切换到 copilot/fix-paper-server-full-bug 分支
  ✅ Switch to copilot/fix-paper-server-full-bug branch in Actions page

🔄 其他运行方法 / Alternative Methods

如果上述方法不work，可以尝试：
If above doesn't work, try:

方法 1: 使用 GitHub CLI
Method 1: Use GitHub CLI

  $ gh workflow run create-release.yml \
      -f tag=1.21.11 \
      -f release_name="EssentialsX 1.21.11 for Paper 1.21.11" \
      -f prerelease=false

方法 2: 推送标签（自动触发）
Method 2: Push Tag (Auto-trigger)

  $ git tag -a 1.21.11 -m "EssentialsX 1.21.11 for Paper 1.21.11"
  $ git push origin 1.21.11

方法 3: 合并 PR 到主分支
Method 3: Merge PR to Main Branch

  将 PR 合并后，工作流会在主分支上可用
  After merging PR, workflow will be available on main branch
